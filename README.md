# Learn to Learn

个人关于"如何学习"的知识库。涵盖间隔重复、主动召回、迁移学习、认知负荷等主题的笔记、心得与可操作清单。

本仓库是 **Obsidian vault**，使用 [obsidian-git](https://github.com/Vinzent03/obsidian-git) 插件做版本控制。

## 浏览方式

- **本地（推荐）**：用 [Obsidian](https://obsidian.md/) 打开本仓库目录，享受双向链接、图谱视图、搜索
- **网页**：直接读 `.md` 源文件，GitHub 会渲染 Markdown

## 内容组织

笔记会按主题归档到子目录，例如：

```
学习科学/
  间隔重复.md
  主动召回.md
学习技巧/
  ...
阅读笔记/
  <书名>.md
```

具体结构随内容增长逐步演化。

## 版本控制说明

- 仓库用 Git 追踪；每次有效改动会形成 commit
- 笔记的 Markdown 源文件、Obsidian 配置（`.obsidian/app.json` 等）入库
- 工作区 UI 状态（`.obsidian/workspace.json`）、缓存、第三方插件二进制**不入库**
- 关闭 Obsidian 时会自动 commit 一次（兜底）
